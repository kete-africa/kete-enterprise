# Tableau

1. Choisis les colonnes qui répondent à la question ; la première nomme chaque ligne.
2. Une ligne par élément ; aligne les nombres, garde les unités dans l'en-tête (« Montant (FCFA) »).
3. Ajoute une ligne **Total** quand les montants s'additionnent.
4. Sous le tableau, une phrase au plus pour ce qui ressort.
5. Ne remplis jamais une case par supposition : écris « — » quand l'information manque.
