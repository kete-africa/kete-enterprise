# Actions

1. Repère chaque engagement : ce qui doit être fait, par qui, pour quand.
2. Formule chaque action par un verbe à l'infinitif (« Relancer le client Mensah »).
3. Propose un responsable et une échéance ; s'ils ne sont pas dits, propose-les et dis-le.
4. Prépare chaque action comme un **brouillon** avec l'outil prévu, jamais comme une décision : la
   personne valide.
5. Récapitule en un tableau : action, responsable, échéance.
