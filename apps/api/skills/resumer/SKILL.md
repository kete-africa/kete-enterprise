# Résumer

1. Lis tout ce que la personne a donné : la conversation, les pièces jointes, les passages cités.
2. Écris **trois à sept points**, du plus important au moins important, une phrase chacun.
3. Ajoute, seulement s'il y en a :
   - **Décisions** : ce qui a été décidé, par qui ;
   - **Actions** : qui fait quoi, pour quand.
4. Garde les chiffres, les dates et les noms exacts ; n'invente rien. Si une information manque,
   dis-le en une ligne.
5. Écris dans la langue de la personne, sans introduction ni conclusion.
